## How I work

- **Model first.** Start with the shape of the data and the rules around it. An honest model gives the interface something solid to stand on.
- **Build the whole path.** Client, server, and database stay connected instead of turning into handoff gaps.
- **Sweat the small states.** Empty, loading, failure, and permission states are part of the product.
